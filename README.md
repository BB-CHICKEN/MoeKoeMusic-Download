# MoeKoe Music Download

一款基于浏览器扩展形式的音乐下载插件，专为 MoeKoe Music 设计。

---

## 功能特性

- **音乐下载** — 一键下载当前播放的音乐，支持多种音频格式（mp3、m4a、flac、wav、ogg、aac 等）
- **下载历史** — 自动记录最近 100 条下载记录，方便查阅
- **封面下载** — 可选同时下载歌曲封面图片
- **精美 UI 动画** — 下载按钮脉冲动画、波浪条纹进度条
- **RPC 下载引擎** — 对接 Motrix/Aria2 RPC 接口，支持远程下载
- **本地设备注册** — 通过本地 6521 端口获取认证信息
- **自定义下载目录** — 可配置自定义下载路径

---

## 安装步骤

### 前置要求

- 浏览器需安装 MoeKoe Music 或能正常访问 MoeKoe 音乐平台
- 本地需安装 **Motrix** 下载器（或其他兼容 Aria2 RPC 的下载器）
- 本地设备需启动 Motrix 的 RPC 服务（默认端口 16800）

### 安装流程

1. 从 [Releases](https://github.com/BB-CHICKEN/MoeKoeMusic-Download/releases/latest) 页面下载最新版本插件
2. 进入 MoeKoe Music 插件管理页面
3. 将下载的插件安装包进行安装
4. 安装完成后重启 MoeKoe Music
5. 启动 Motrix，确保 RPC 服务正常运行
6. 享受音乐下载功能

### 配置说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| RPC 地址 | `http://127.0.0.1:16800/jsonrpc` | Motrix RPC 服务地址 |
| RPC 密钥 | 空 | Motrix RPC 认证密钥（如需） |
| 自动启动 Motrix | 开启 | 检测到 Motrix 未运行时自动启动 |
| 下载封面图片 | 关闭 | 同时下载歌曲封面 |
| 下载目录 | 空 | 自定义下载保存路径（需为绝对路径） |

## 使用方法

1. 在 MoeKoe Music 中播放任意一首音乐
2. 点击播放器区域出现的下载按钮（下载图标会有脉冲动画效果）
3. 当前播放的音乐将被添加至 Motrix 下载队列
4. 可在下载历史中查看最近 100 条下载记录
5. 下载文件将以 `艺术家 - 歌曲标题` 的格式命名

---


### 核心模块

- **ConfigManager** (`content.js:14`) — 配置管理与历史记录
- **MotrixRPCClient** (`content.js:128`) — RPC 客户端，负责与 Motrix 通信
- **DownloadManager** (`content.js:313`) — 下载管理器，处理页面交互与下载逻辑

## 常见问题

**Q: 点击下载按钮没有反应？**
- 检查 Motrix 是否已启动
- 检查 RPC 地址配置是否正确（默认 `http://127.0.0.1:16800/jsonrpc` ）
- 打开浏览器开发者工具查看 Console 日志排查错误

**Q: 提示无法连接 Motrix？**
- 确认 Motrix 正在运行且 RPC 服务已开启
- 检查端口号是否被防火墙拦截

**Q: 下载的文件名乱码或包含特殊字符？**
- 插件会自动过滤 Windows/Linux 非法字符，将其替换为下划线
- 若文件名过长会自动截断至 200 字符以内
